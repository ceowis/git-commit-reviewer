# Git Commit Reviewer

Git 변경 사항을 분석하여 코드 리뷰, 커밋 메시지 생성, Pull Request 초안 작성을 지원하는 Kiro Power입니다.

## 주요 기능

### 코드 리뷰

Git Diff 또는 소스 코드 변경 사항을 분석하여 다음 항목을 점검합니다.

- 가독성
- 유지보수성
- 성능
- 보안
- 예외 처리
- 테스트 누락 여부

### 커밋 메시지 생성

Conventional Commit 규칙에 따라 커밋 메시지를 생성합니다.

예시

```text
feat(auth): 로그인 실패 횟수 제한 기능 추가

fix(order): 주문 취소 상태 저장 오류 수정

refactor(user): 사용자 조회 로직 단순화
```

### Pull Request 초안 작성

변경 내용을 분석하여 다음 항목을 자동 생성합니다.

- 변경 목적
- 주요 변경 사항
- 영향 범위
- 테스트 방법
- 위험 요소

---

## 사용 예시

### 코드 리뷰

```text
이 git diff를 리뷰해줘
```

### 커밋 메시지 생성

```text
이 변경사항에 대한 커밋 메시지를 작성해줘
```

### PR 초안 작성

```text
PR 설명 작성해줘
```

---

## 출력 예시

### 변경 사항 요약

사용자 조회 기능 추가

### 리뷰 결과

- 예외 메시지 누락
- 테스트 코드 추가 필요

### 개선 제안

- Custom Exception 사용 권장

### 커밋 메시지

```text
feat(user): 사용자 조회 기능 추가
```

### PR 초안

```markdown
## 변경 목적

사용자 조회 API 추가

## 주요 변경 사항

- UserService 추가
- UserRepository 추가

## 테스트 방법

- 사용자 존재 시 정상 조회
- 사용자 미존재 시 예외 발생
```
